# 勞工大代誌 · Taiwan Labor Data

[English](README.md) | [繁體中文](README.zh-TW.md)

## 這是什麼

一個繁體中文的互動網站，整理台灣 2012 至 2025 年的公開勞動統計：薪資、工時、
失業率、最低工資與消費者物價、移工的產業與國籍分布、戶籍人口年齡結構，以及出生
人數與粗出生率。網站另外收錄 31 則勞動紀事，從 1886 年的乾草市場事件到 2026 年
的外送專法。每張圖表都附資料表格，資料也提供 CSV 與 JSON 下載。

資料來源為主計總處、勞動部與內政部的公開統計。年度序列只到最後一個完整年度，現行
最低工資與年度序列分開計算，薪資未做通膨調整。

「我的薪資級距」可直接填入稅前年薪，對照主計總處 2024 年
全年總薪資分布，以年薪為橫軸、人數為縱軸。平均數與中位數取自官方 Excel；人數由
官方區間占比換算，標示為推估值。結果顯示大約在前幾%，依官方 D1–D9 分界線性插值，133.6 萬元以上以校準至前 10% 的薪情平臺高薪分布推估；年薪超過 200 萬元顯示「超標」與「你真是太厲害啦！」，剛好 200 萬元仍顯示估算排名。結果可下載為 PNG，供分享。輸入值不會儲存
或傳送至伺服器。開啟 `/#salary` 可直接前往計算器。

網站以 TanStack Start、React 與 Vite+ 建置，部署在 Cloudflare Workers。設計決策、資料來源、統計方法、資料
維護與部署方式，請見 [DESIGN.md](DESIGN.md)。

## 開始使用

安裝 Node.js 22.12 以上，然後在專案目錄執行：

```sh
npm ci
npm run dev
```

打開終端機顯示的網址。預設連接埠是 3001，被占用時伺服器會改用其他可用的連接埠。

已查核的資料集包含在此儲存庫中。執行網站不需要外部 API、憑證、Python 或資料庫
伺服器。

在本機建置並預覽正式版本：

```sh
npm run build
npm run preview
```

## 參與貢獻

要回報問題或提出修改，請開一個 issue。要修改程式，請建立分支，完成修改，並在開
啟 pull request 前執行檢查：

```sh
npm run check
npm test
npm run build
```

請說明修改內容與驗證方式，介面變更請附截圖。修改介面時，圖表資料表格、鍵盤操作與
減少動態支援都必須維持可用。`npm run test:browser` 會操作真實的 app，在 375、
768 與 1440px 覆蓋這些流程。

修改資料請依照 [DESIGN.md](DESIGN.md) 的資料維護說明：重建並驗證快照，檢查來源
與驗證結果的變更，並在 pull request 中寫出每項更正的來源。
